2. 新增/修改接口请求参数
2.1 顶层参数
--- TABLE ---
字段 | 类型 | 必填 | 说明
requestId | string | 否 | OA 请求号（当前版本未使用）
persons | array | 是 | 人员数组，包含 1~2000 条人员数据
--- END TABLE ---
2.2 persons 元素参数
--- TABLE ---
字段 | 类型 | 必填 | 说明
pin | string | 是 | 工号，平台唯一键（也是设备用户号）
name | string | 是 | 姓名
oaUserId | string | 否 | 泛微用户唯一 ID（平台建唯一索引映射）
dept | string | 否 | 部门
cardNo | string | 否 | 卡号
status | string | 否 | ACTIVE 在职（默认）/ RESIGNED 离职；离职会自动清空全部组归属并在设备端禁用
pri | int | 否 | 设备用户权限，0=普通（默认）
photo | string | 否 | 人脸注册照。要求：Base64 编码 JPG，≤500KB；支持 data:image/jpeg;base64, 前缀；不可传图片 URL；不合规仅丢弃照片不影响入库；更新时未携带则保留原照片
accGroups | string[] | 条件 | 门禁组名称数组，全量语义（详见下方规则）
fingerprints | array | 否 | 预留字段，当前版本不处理
devices | array | 否 | 预留字段，当前版本不处理
--- END TABLE ---
2.3 accGroups 全量语义规则
未携带（null） → 不处理该人的组归属
空数组 [] → 清空该人的全部组归属
非空数组 → 以本次推送为准，diff 自动加组/退组
注意：组名须与平台门禁组精确匹配且为启用状态；若组不存在/已停用/目标组之间存在同设备冲突 → 该人 FAILED 且不做任何变更，其余人正常处理

6. 对接注意事项
幂等重推安全：同一人重复推送结果一致，可放心重试。
photo 契约：必须为 Base64 编码的 JPG 图片，大小 ≤500KB；传 URL 会被明确拒绝（日志可见）。
组名校验：使用示例组名联调前，请确认平台已建同名门禁组，否则该人 groupResults 将返回 FAILED。
异步下发：接口返回仅代表受理成功，设备端写入状态需通过 GET /api/persons/sync-status?pin=xxx 查询；失败行由平台 10 分钟对账自动重试。
